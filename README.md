# Student Grade Tracker System 🎓

## 📌 Project Overview
The Student Grade Tracker System is a Java-based application designed to manage student academic records and calculate their academic performance.

It helps users store student details, enter subject marks, calculate total marks and percentage, and track student grades in an organized way.

## 🎯 Objectives
- To manage student academic information.
- To record marks for different subjects.
- To calculate total marks and percentage.
- To determine student grades based on performance.
- To make grade management simple and efficient.

## ✨ Features
- Add student details.
- Enter marks for multiple subjects.
- Calculate total marks.
- Calculate average and percentage.
- Display student grades.
- View student performance.

## 🛠️ Technologies Used
- **Programming Language:** Java
- **IDE:** Eclipse
- **Concepts:** Object-Oriented Programming (OOP)

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Open Eclipse IDE.
3. Select **File → Import → Existing Projects into Workspace**.
4. Browse and select the project folder.
5. Open the main Java file.
6. Click **Run** to execute the project.
